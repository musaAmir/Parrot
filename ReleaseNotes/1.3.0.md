# Parrot 1.3.0

- Rebuilds Settings with a native unified toolbar, colored sidebar badges, compact AppKit controls, and grouped cards matching Hush.
- Adds a Recordings view with start, pause, resume, stop, playback seeking, and save actions, accessible from the menu bar.
- Adds a recording-panel preview and optional pause/stop buttons under Appearance.
- Replaces the bright icon with a darker charcoal and muted teal parrot.
- Starts microphone capture after the start cue finishes plus a 150 ms echo gap, preventing the cue from being captured through external speakers. Wait for the timer before speaking. Recording starts immediately when feedback sounds are off.
- Cancels a pending start if the shortcut is released or the take is stopped during the cue. Playback waits for the stop cue to finish.
- Uses the macOS 27 permission name, Device Control and Data Access, while retaining Accessibility wording on older macOS versions.
- Uses a consistent certificate identity for signed development builds and keeps build products out of Spotlight and Alfred search results.

Requires macOS 14 or later. Includes Apple silicon and Intel binaries. Versions 1.2.0 and later can find this release through Check for Updates.

**Permissions:** Replacing an older ad-hoc build can require one new approval. Microphone and Device Control and Data Access approvals were retained across replacement of the signed local build. Keep the same signing identity for subsequent builds.

**Validation:** Recording, shortcut, cue-timing, cancellation, pause/resume, file-retention and update-configuration regression tests; release metadata and Sparkle archive/feed signatures and tamper rejection. Intel is cross-compiled and still needs physical hardware validation. The cue timing is tested; acoustic echo varies with the speaker and room.
